# Vault-Talk

The launcher for two companion mods that give the characters of Fallout a mind (an LLM) and their own
cloned voice:

- **Courier's Company** — Fallout: New Vegas
- **Survivor's Company** — Fallout 4

Each mod works on its own: you only need the game you play.

## What it does

- Finds your games (Steam, GOG, Epic, or any folder) and whether you use Vortex or Mod Organizer 2.
- A checklist of what each mod needs, with a button for whatever is missing.
- Sets up the AI (Player2 with one click, OpenRouter, OpenAI, Gemini, a local model) once for both games,
  or separately for each.
- Finds the voice engines already on your PC (Pocket TTS, OmniVoice) or installs them.
- Tests outside the game: one question to the AI, one spoken line.
- Diagnostics: reads the logs, finds the errors and copies a report with no keys or personal data in it.
- Updates itself.

It is only a helper. Once things are set up, start the game as you always do: the mods don't need the
launcher open.

## Download

**[VaultTalk.exe](https://github.com/CarlosNahuelcoy/Vault-Talk/releases/latest)** — one file, nothing to install
(Windows 10/11; it also runs under Proton on Linux).
